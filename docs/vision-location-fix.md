# Camera and location repair — 6 September 2026

The production device stream now asks Gemini to classify each natural-language turn before requesting evidence. Recent conversation resolves follow-ups. Classification distinguishes live visual inspection, reading, visual memory, recall and general/device-context requests. Camera keywords no longer decide production routing. Both audio and text turns can request a fresh frame. Explicit client intent remains supported. A failed classifier returns a recoverable error rather than inventing a camera-free answer; cancelled classification cannot resume an old turn.

The existing keyword helper remains only as the default for integrations that do not supply a classifier; server.ts explicitly supplies the semantic router. Do not remove that wiring. The router uses the configured Gemini model with structured, validated output and a bounded request. The live evaluation script is `node --import tsx scripts/evaluate-intent.ts` with GEMINI_API_KEY supplied through the existing secret mechanism. It exercises visual paraphrases, conversational references, figurative language, general questions and camera refusal. It is an evaluation, not a guarantee of understanding every ambiguous request.

Android changes in the companion repository actively warm foreground location and request a bounded current fix instead of relying on lastLocation. They also restart camera capture on foreground return and separate camera availability from automatic recording. The Android update is required for these sensor fixes; updating only the server cannot repair an installed client's location acquisition.

Physical-device acceptance: ask several differently phrased visual questions, an OCR request, then a general/time question; verify only the visual turns upload frames. Grant camera/location in Settings and return; retry without force-closing. Test precise and approximate location, a cold GPS start, disabled location services, denied permissions and leaving the app mid-request. Preserve unavailable/stale states when sensors genuinely cannot supply evidence. Location is not navigation or a road-crossing signal.
